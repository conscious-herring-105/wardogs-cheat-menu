# WARDOGS Cheat Menu — feature reference

WARDOGS Cheat Menu brings target-selection and aim controls, player and world ESP, combat adjustments, and configuration profiles into a single menu.

| Section | Description |
|---|---|
| Aiming | Target selection, field-of-view settings, smoothing, visibility checks, and activation-key settings. |
| Visuals / ESP | Player outlines and skeletal display categories; health, name, distance, vehicle, and item information. |
| Combat controls | Recoil, weapon-sway, view, and crosshair settings. |
| Configuration profiles | Save, restore, and organize configuration settings. |

The project page follows the same section structure.
